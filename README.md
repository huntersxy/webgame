# 乐下 · 网页游戏平台

简洁清新的网页小游戏平台。当前上线：**龙卷风成长记**、**五子棋**、**中国象棋**、**军棋（陆战棋：人机 / AI 互搏）**——不局限于棋类，休闲小游戏持续上新。
本地运行、免注册、断网可玩；棋类 AI 在 Web Worker 中计算。

## 技术栈

- **TypeScript** — 全量类型安全，`strict` 模式
- **Vite 6** — ES 模块构建，HMR 热更新，生产优化
- **Web Workers** — AI 搜索在独立线程运算，UI 永不卡顿
- **Hash 路由** — `#/`（平台首页）· `#/tornado` · `#/gomoku` · `#/campaign` · `#/xiangqi`
- **Canvas 2D** — 木纹棋盘渲染，落子动画，思考可视化
- **Web Audio API** — 程序化合成音效，零音频文件依赖
- **😈 恶魔主题** — 恶魔模式下浮现「褚赢」AI 形象面板并播放专属 BGM

## 五子棋引擎 v3（全新重写）

面向「最强 + 最快」的现代自由式五子棋算法栈：

- **O(1) 增量评估** — 572 个五连窗口 + 形状分值表，落子/撤销只更新受影响的 ≤20 个窗口；叶节点评估是一次减法，不再全盘扫描
- **强制着法逻辑** — 即时成五点集合（win-cell stack）O(1) 维护：自己有成五点 → 立胜；对手双成五 → 必败；单成五 → 分支坍缩为唯一堵点，战术局面搜索树大幅剪枝
- **迭代加深 α-β + PVS** — 每档难度按真实时间预算加深（简单 150ms → 恶魔 2.8s），不再固定层数
- **Zobrist 增量哈希 + 深度优先置换表** — 跨迭代复用
- **威胁延伸** — 冲四 / 活三着法延伸搜索深度（带预算），杀棋看得更远
- **VCF 连续冲四搜索** — 独立战术引擎，在主搜索之前证明远深度必杀序列
- **杀手着 + 历史启发** 排序；候选生成零分配（逐层复用 typed-array 暂存）

实测：普通档 ~450ms 达 depth5；恶魔档 2.8s 内中局 depth8+，nps ≈ 0.3M/s。

### 设计原则

- **规则 / AI / 渲染 / 控制器完全分离** — 每层可独立测试和替换
- **Web Worker 隔离 AI** — 恶魔级深度搜索不再冻结 UI
- **引擎无副作用** — 搜索不改动传入棋盘，`tests/engine.test.mts` 用随机落子对拍验证增量状态一致性
- **Promise 化 Worker 通信** — `AIBridge` 封装异步搜索 API

## 玩法

### 平台首页（`#/`）
游戏库卡片、平台特性、累计战绩统计；「新游戏筹备中」占位卡展示平台定位（不限于棋类）。

### 🌪️ 龙卷风成长记（`#/tornado`）
大鱼吃小鱼式成长休闲游戏，纯 Canvas 2D，无外部资源：
- 操控小龙卷风，**卷走比自己小的物体**按面积增量成长；**撞上更大的只会被弹开、零惩罚**
- 物体脚下绿实线圈 = 可卷走，红虚线圈 = 会被弹开，一眼分辨可食性
- 清空一个量级后**镜头自动拉远**（缩放动画 + 相对缩小），生成下一量级物体
- 六大量级：街道内 → 大楼房 → 城市 → 国家 → 洲 → 全地球，通关后计入平台战绩
- 键盘（WASD/方向键）+ 指针/触屏按住牵引；得分本地最高分记录

### ⚫ 五子棋（`#/gomoku`）
- 人机 / 双人 / AI 互搏，执黑 / 执白，四档难度（含 😈恶魔）
- 功能：新开、悔棋、求一着、请神上身、音效、局势条、移动端触控适配
- 🧠 思考可视化：深度 / 节点数 / 用时 / 评估 / 候选点
- 😈 恶魔难度：对手即「褚赢」，附带专属头像与 BGM；输给人类会记入败局档案并学习

### ⚔️ 战役（`#/campaign`）
- 五子棋风格对决，每关 AI 风格不同，破防获胜解锁下一关
- 进度自动保存到 localStorage

### ♞ 中国象棋（`#/xiangqi`）
- 完整规则：马腿、象眼、宫、河界、炮架、飞将、将军/绝杀/困毙判负
- 执红 / 执黑（执黑自动翻转），翻转棋盘，双人 / 人机，四档难度
- AI：子力 + 位置价值表 + MVV-LVA 排序 + Alpha-Beta + TT + 将军延伸 + Quiescence

### ⚔️ 军棋 · 陆战棋（`#/junqi`）
人机对战 / AI 互搏观战，完整陆战棋规则 + 两种玩法：
- 每方 25 枚，司令→工兵九级大吃小、同级同归于尽；炸弹与任何子互炸；地雷只有工兵能挖；军旗被扛即负；无子可动判负，240 手判和
- 地形：行营（圆）内不可被攻击、大本营置旗、天堑河流仅三座桥可渡
- 铁路（双线）上普通子直线滑行、工兵可在铁路网任意拐弯；公路与行营斜线每次一步
- **明棋 / 揭棋人机 · 自定义摆阵**：点击兵种放入棋盘自由布阵（军旗入大本营、地雷后两排、炸弹不进第一排、行营留空，实时校验），也可随机 / 补全；执红先行或执蓝后走（自动翻转棋盘）
- **揭棋（暗棋）**：双方棋子对对方暗置，自己始终可见己方；己方棋子攻击对方暗子时守方翻明，攻方不翻明——吃子后继续潜伏，攻方阵亡则守方保持明牌；AI 对暗子按期望子力评估
- AI：子力 + 前进 / 旗位压力评估 + MVV 排序 + Alpha-Beta + TT + 杀手着 + 静态搜索，恶魔档迭代加深（Web Worker 运算）
- 支持悔棋、求一着、AI 互搏暂停、走法记录、思考可视化（深度 / 节点 / 评估 / 主变）
- 规则引擎自测见 `tests/junqi.test.mts`
